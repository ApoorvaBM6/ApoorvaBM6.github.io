{%- comment -%} Privacy-friendly visitor analytics (Umami Cloud) with OPT-IN consent. - Nothing is loaded, sent or stored for analytics until the visitor clicks "Accept" in the banner. The only thing written before that is the visitor's own choice (localStorage "analytics-consent"), which is strictly necessary to remember the answer and is kept for 6 months. - The Umami tracker loads only in production builds (GitHub Actions sets JEKYLL_ENV=production) and only when site.analytics.umami_website_id is set in _config.yml. - The Website ID is a public identifier, not a secret; no API key ever lives in this repository. - Global Privacy Control / Do Not Track are treated as a refusal: no banner, no tracking. - Append ?analytics-debug to any URL to show the banner locally and log events to the console. {%- endcomment -%} {%- assign umami_id = site.analytics.umami_website_id | default: "" | strip -%}
