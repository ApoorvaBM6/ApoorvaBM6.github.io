Recorded and analyzed **pilot cognitive workload and attentiveness** during simulated flight tasks using real-time **EEG and ECG** physiological monitoring.

Implemented an **auditory oddball paradigm** using an 8-channel dry-electrode Enobio EEG system and Faros ECG sensors during active piloting and monitoring phases. Processed EEG signals using **Matlab and EEGLAB**, applying FIR filtering, epoching, artifact rejection, ERP analysis of **N100 and P300**, and alpha-band (8–12 Hz) spectral analysis. Performed **ECG and HRV analysis** using Kubios HRV to evaluate heart rate, LF/HF ratio, and workload-related physiological changes.
