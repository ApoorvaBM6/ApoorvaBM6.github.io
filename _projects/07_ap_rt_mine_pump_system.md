Developed a **real-time mine pump control system** in **C** using **RTOS concepts and RTEMS**, with task scheduling and resource-sharing mechanisms for reliable real-time operation.

The project modeled system tasks considering **precedence constraints, schedulability, and worst-case response-time analysis**, while implementing periodic task execution and **inter-task communication using message boxes**. Applied the **Immediate Priority Ceiling Protocol (IPCP)** and developed modular C components for real-time system functionality.
