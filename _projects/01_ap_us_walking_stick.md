Designed and implemented an **ultrasonic obstacle-detection and alert system** to assist visually impaired users in navigating safely by providing an audible warning when obstacles are detected.

Developed an **Arduino-based embedded system** using an **HC-SR04 ultrasonic sensor** to measure the distance to obstacles and a buzzer to provide distance-dependent audio feedback. Implemented real-time distance calculation from ultrasonic echo timing and configured different buzzer frequencies for obstacles within **100 cm** and **50 cm**, providing increasingly urgent feedback as the user approaches an obstacle.

The system was built using an **Arduino Uno, HC-SR04 ultrasonic sensor, buzzer, switch, and 5V battery**, with the complete sensing and alert logic implemented in **Arduino C**.
